# Paper Notes

Keep one markdown note per paper only when deeper extraction is needed.

Minimum fields: Paper, source, technique, problem addressed, assumptions, delta vs B0/B1, transfer rationale, rule/license risk, cheapest falsification test, expected information value, and decision (IGNORE/WATCH/TEST).

Do not copy long passages from papers. Record claims as paraphrased evidence and convert only actionable ideas into `../idea_cards/`.
