# Proposed next localization mechanism: trajectory-conditioned spatial heatmap

**Recommendation: a bounded coverage and two-movie benchmark is justified. Do not launch a full fit until those controls pass.** Use one small spatial heatmap model with three predicted-trajectory image views, exact reflection symmetrization, and conservative abstention. This is a different inductive bias from C058's flattened offset regressor. It is not a claim of improvement and does not reopen the fixed C058 recipe.

## Why this mechanism, rather than another registration pass

C058 represents source labels (sampled mean errors 1.712→0.726µm and 1.955→1.302µm) but transfers poorly. Opposite predictions have large directional bias; their tail z means even point against the required mean shifts. A flattened dense coordinate head can memorize an absolute offset prior. A fully convolutional spatial map retains alternatives, while exact reflection averaging cannot retain a fixed output-vector bias unrelated to image geometry.

The identity audit also finds persistent residuals on correctly tracked cells and abrupt matching switches near missed links. A three-frame predicted trajectory supplies information about which local structure persists. It does not make the trajectory biologically correct. The model must keep alternatives and abstain when observations disagree.

Reuse `local_registration_probe.py` / `c051_boundary_registration.py` for any image-transport checks; do not rebuild them. Pure registration preserves a point's initial offset and therefore cannot determine the absolute annotated center. C036/C051 are already closed; C051's additional 484 trusted groups recovered no new annotated match. Registration can later test consistency of a proposed center, but it is not the primary next localization mechanism.

## One concrete geometry and learner

1. Use **13×49×49** real, full-resolution crops centered on the actual integer predecessor/current/successor predictions. Eligible context is a unique, contiguous, nonbranching predicted three-node path, with complete support for all three crops and no synthetic node. Center each view on its own prediction, so temporal channels expose consistency of the local structure relative to the existing path. Never use GT coordinates to select runtime context. Missing/ambiguous context keeps C023 unchanged. This is temporal context for localization, not the deferred division-morphology experiment.
2. Store **15×57×57** expanded crops for exact shared integer center jitter z±1 and y/x±4. The same jitter is applied to all three crops; the target offset changes by minus that physical displacement. Reject a jitter that moves the known target outside the existing 7µm localization support, preserving the original unjittered point. Odd crop sizes make each axis reflection exactly `d→−d`, without C058's even-grid half-voxel correction.
3. Suggested compact head: stack the three image channels; two **valid** Conv3d blocks (widths8 then16, kernels3×7×7, stride1), pointwise activation and optional normalization over channels at each voxel only; then a1×1×1 scalar-logit head. This yields a **9×37×37** grid with offsets z=−4…4 and y/x=−18…18 input voxels around the original center. Every output has real receptive-field support. This grid covers the entire discrete 7µm sphere. Use no flattening, dense coordinate layer, absolute coordinates, embryo identifier, or padding-generated image context. The limited receptive field is a risk to measure, not a reason for an architecture sweep.
4. Interpret logits inside that fixed physical sphere as the **conditional location distribution of the supplied trajectory's point**. Train on known source-embryo center targets, with a Gaussian target of one input voxel standard deviation per axis and a conditional distribution loss. This is not a whole-image cell/background detector: unannotated cells never receive false-cell/background labels. Explicitly retain the distinction; conditional competition can still be harmful if the selected trajectory identity is wrong.
5. Training supervision should initially require the source center and both neighbors to match the same known GT lineage through the two known edges. Report how many source points, tail points and independent annotation windows remain per embryo. This removes demonstrated identity contradictions from source supervision, but biases the training set toward correct existing paths. It cannot be called supervision for repairing known identity switches. Runtime eligibility uses predicted paths only, so its domain is broader; that is an explicit validation risk.
6. Reuse the registered optimizer/step budget and whole-embryo scheme unless the benchmark exposes a concrete feasibility issue: AdamW3e-4, 1,200 steps, batch32, seed fixed before launch, final checkpoint only. Uniform movie then eligible point remains transparent. Apply one uniformly sampled member of the **eight z/y/x reflection group** jointly to all views and the target per sample. No z↔x/y axis exchanges because voxel spacing is anisotropic. A fixed modest affine intensity augmentation can be registered to reduce appearance-domain dependence; it must preserve coordinate labels and pass the invariance check below. No target-embryo tuning.

## Exact reflection rule and protection of existing nodes

At inference, evaluate the eight reflected inputs, inverse-reflect their **logit grids**, and average those aligned grids. Apply the radial mask and normalize afterward. This group-average construction is exactly reflection-equivariant up to numerical precision when valid support, the radial mask and tie handling are symmetric. It does not promise arbitrary rotation invariance or immunity to domain shift. Translation equivariance is only asserted on common valid image support, with the search window and anchor transformed consistently.

Use a spatial mode, not the mean of separated peaks. Predeclare these conservative abstentions without target-selected thresholds:

- Each of the eight unaveraged, inverse-reflected maps must have the same unique integer mode. A tie, flat output or disagreement keeps the original coordinate. This specifically blocks orientation-dependent offset priors. Measure its actual coverage; do not relax it after seeing evaluation scores.
- The agreed proposal must remain in the original prediction's nearest-center spatial ownership region among current-frame predicted nodes. Otherwise keep the original coordinate. All predictions are competitors for identity, not biological negative labels. This guard prevents a correction from simply taking a neighboring prediction's location; it can also reject a genuine correction and must be counted.
- If the agreed proposal equals the original integer center, retain it exactly. Never move excluded or synthetic nodes. Report effects on original ≤2.5µm points and already-correct edges; these GT strata are evaluation only. No runtime guard can guarantee that all biologically correct nodes are protected.

The strict mode agreement may yield few or zero changes. That is a valid mechanism failure, not justification for confidence/temperature/threshold sweeps. Reflection averaging by itself can also collapse a weak model toward the center; exact original-coordinate fallback and coverage reporting distinguish this from successful correction.

## Cheap falsification before a full queue

1. **Coverage/data audit, no fit:** whole-embryo source counts after three-frame known-lineage supervision; separate persistent residuals from abrupt identity switches; unknown alternatives, real-image support, fork/synthetic exclusion, and duplicated contexts. If either embryo loses essentially all hard labels, this recipe does not test the motivating failure and should not launch unchanged.
2. **Algebraic controls:** on a synthetic asymmetric blob embedded in real-supported array geometry and real source crops, verify exact odd-grid reflection/target transform, the eight-view averaged-map transformation, crop jitter sign/units, common-support translation, tie-to-baseline behavior and identity-ownership abstention. Constant/flat logits must leave the graph unchanged. Use the existing original writer/scorer for zero parity; do not create an evaluator.
3. **Invariance controls:** fixed small positive intensity gain/bias and joint reflection should preserve the transformed target. Evaluate geometric consistency on source crops before any target scoring. A model that changes coordinate solely under a label-preserving photometric transformation is not yet supported for deployment. Symmetry controls are necessary but not evidence of biological identity or localization gain.
4. **Two full movies:** measure actual extraction, eight-view inference, peak-agreement coverage, ownership rejections and memory. Only then register the queue's runtime/ETA and the user-requested native Windows completion watcher. A small head and current ~22-hour deadline make this plausible, but no runtime estimate is asserted before measurement.
5. **One fixed opposite-embryo pilot:** paired localization must improve on both embryos, especially the persistent-tail stratum, without increasing error/lost identity among originally good nodes. Report all abstained nodes and failures, not only changed survivors. Official graph metrics on frozen final edges remain required for safety and coverage/rematching effects.

If the component passes, its upstream value requires a **separate exact-control replay before association**. Frozen final edges cannot improve merely because residuals decrease while GT matching stays unchanged. The provisional C023 trajectory supplies the context for this second-pass hypothesis; full detector/feature/association dependencies must be respected rather than editing coordinates inside a stale cache. Root is auditing that integration point. No current output or detector anchor should be overwritten.

## Remaining risks

The annotation center may differ from a bright image center; raw-peak snapping is unsupported by the spatial audit. Reflection-equivariance cannot fix wrong operational identities. Source GT-lineage filtering may remove precisely the difficult cases of interest. Predicted temporal context can consistently follow the wrong nearby cell; ownership guards may lock that identity. The heatmap can learn an uninformative central prior, and a highly multimodal distribution can give an unstable mode. Full source-domain fit is not validation; opposite-embryo results and actual graph evidence determine continuation. This proposal authorizes a bounded mechanism test, not automatic promotion or submission.
