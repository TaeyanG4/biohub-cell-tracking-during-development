# 성능 개선 방향 재검토 — 2026-09-29

사용자는 특정 0.001–0.002 개선폭에 얽매이지 말고 점수를 높일 방법을 찾도록 요청했다.
이번 검토는 C057을 다시 학습하거나 기존 실패 설정을 조정하지 않고, 다른 정보와
구조를 추가할 수 있는지를 확인했다. 새로운 공식 점수 개선은 아직 입증되지 않았다.

## 우선 방향: 원본 영상에 기반한 위치 보정

현재 가장 근거가 큰 후속 실험이다. 기존 C023 진단표를 다시 집계한 결과:

- 양 끝 검출이 존재하는 누락 연결 1,385건 중 1,047건(75.6%)은 한쪽 이상 위치 오차가 3.5µm 초과.
- 해당 누락 연결의 실제 이동 중앙값은 2.63µm, 연결해야 할 예측 좌표 간 거리는 8.30µm.
- 오류에 연관된 세포의 위치 오차 중앙값은 3.83µm, 나머지는 1.72µm.
- 기존 자체 좌표-head 데이터는 기본적으로 4µm 내 매칭을 수집하고 3µm 이하로 학습한다.
  공개 x138 head의 정확한 학습 필터는 알 수 없다. 두 head 모두 압축된 UNet 특징을 쓰며,
  보정 크기를 단순히 키우는 것은 기존 감사에서 전체 오차를 악화시켰다.

가설: 연결 문제로 보이는 일부 오류는 세포 중심/동일성의 공간적 불안정에서 발생한다.
원본 고해상도 3D crop을 보고 위치를 예측하는 별도 모델은 현재 head에 없는 정보를 쓸 수 있다.
다만 큰 오차는 다른 핵에 잘못 매칭됐거나 주석 위치가 달라서 생겼을 수도 있다. 위 숫자는
연관성과 실험 우선순위의 근거이지 모두 고칠 수 있다는 주장이나 점수 예측이 아니다.

첫 검증은 C023 최종 노드 ID·개수·연결을 고정하고 좌표만 보정한다. 기존 공식 매처/평가기,
정수 CSV 규칙, 원영상 읽기/crop 도구를 재사용한다. 학습은 한 배아, 적용은 반대 배아 전체다.
미주석 세포는 배경 정답으로 쓰지 않는다. 제로 보정은 기존 점수와 완전히 같아야 한다.
두 배아의 실제 공식 edge/total, TP/FP/FN, 분열과 정상 좌표 손상을 함께 판단하며,
좌표 MSE만 좋아진 후보는 진행하지 않는다. 양쪽에서 일관되면 같은 방식으로 97개에 확장한다.

상세 실행 설계와 중단 조건: [structural/REVIEW.md](structural/REVIEW.md).
아직 이 모델을 학습하거나 장시간 큐를 시작하지 않았다. 먼저 두 영화 전체 노드의
crop/inference 비용과 학습 라벨의 동일성·경계 처리를 확인해야 하며, 현재 PID/ETA는 없다.

## 병렬 조사 1: 다른 공개 연결 모델

Hengck model_v12/00000008의 필요한 코드와 약43MB 체크포인트만 확보해 직접 실행했다.
기존 C023 검출 좌표를 그대로 입력할 수 있음과 공개 특징 추출/좌표 변환의 정확성을 확인했다.
이것은 이전 C056 StrongUNet 검출 추가와 다른 모델 및 적용 방식이다.

고정된 193입력/1,834정답 연결의 순위 검사에서 기존 모델의 오류16건을 고쳤으나
맞던37건을 틀렸다. 전체 정답1782→1761. 따라서 전면 교체나 무조건 평균 결합은
현재 근거로 권하지 않는다. 추가로 사전 고정한 부모확률50:50평균 한 가지도 검사했으나
10건 순위 개선/22건 훼손,두 배아 모두 감소했다. 이 두 고정 방식은 전체 영상 실험으로
진행하지 않는다.16건의 보완 신호는 보존하되 실제 그래프 개선으로 부르지 않는다.
미주석 경쟁자는 C057의 고정 조건부 부모 identity mask를 그대로 사용했으며,
새 학습/점수 선택/그래프 수정은 없었다. 이 공개 모델도 동일 원영상에 노출됐으므로
독립 검증 모델이라는 의미의 '독립'은 아니다.

## 병렬 조사 2: 여러 시점의 분열 형태

기존 C049/C050에는 없는, 예측 궤적을 따라 t+3까지 보는 크기 변화는 측정 가능했다.
C023 두 영화에서 기존 후보 열거/MetricLabeller로 829,111후보를 검사했다.
양성10행은 주석 분열4개의 중복 후보이며, 독립 사건10개로 해석하면 안 된다.
138개 표본을 원영상에서 측정하는 전체 실행은 약34초였다.

strict 양성의 t+3 크기비도0.657/1.037/1.778로 달라 단순한 '작으면 분열' 규칙은
뒷받침되지 않는다. 후보의 약98%는 미주석이며 그대로 unknown이다. 표본을 라벨별로
뽑았으므로 모집단 precision을 추정할 수 없다. 기존48특징 대 새8개 크기/밝기/가용성
특징 추가의 고정 양배아 비교는 별도 연구 가치가 있지만, 바로 그래프에 넣지 않는다.

## 장기 구조 방향

위치 문제를 확인한 다음에는 부모와 두 딸세포의 여러 프레임 궤적을 한 사건으로
평가하는 연결 모델이 후보가 된다. 현재 한 쌍씩 산출한 edge 확률은 ILP의 노드 선택도
바꾸며, 뒤의 일대일 relink는 분열을 지운 뒤 별도 규칙으로 복구한다. 이 상호작용은
C057의 노드16,270개 증가에서도 나타났다. 다만 C057은44b6 raw edge부터 나빠졌으므로
노드 수를 고정하는 것만으로 기존 실패 모델을 구제할 수 있다고 보지 않는다.
C033/C038/C048의 기존 고정 가중치·appearance 치환을 반복하는 실험도 아니다.

추가로 GT가 아닌 이미지 phase shift만 사용한 좌표 스무딩 오차 보정 proxy를 확인했다.
44b6의 프레임 중앙잔차는1.013→0.970µm였으나6bba는1.220→1.278µm로 악화했다.
이 단순 보정은 우선순위에서 제외한다. 실제 official replay 결과로 해석하지 않는다.
근거: [motion/diagnostic.json](motion/diagnostic.json).
