# 전체 결과 확인 후 최종 선택

최신 권고: **C069(56678906) + C024(56541277)**. 이전 C053+C024 권고는 C069 공개 결과 확인 전 판단이며 본 문서가 대체합니다. 실제 Kaggle 선택은 변경하지 않았습니다.

사용자 요청에 따라 C067/C069/C070의 정확한 접수 ID를 한 번씩 조회했습니다. C0670.954, C0690.954, C0700.953이며 모두 COMPLETE/오류 없음입니다. private 점수나 다른 제출물 점수는 조회하지 않았습니다.

C069는 같은 실제 공식 로컬 평가에서 C053 대비97 +0.000571918, 나머지75 +0.000715071, 44b6 +0.000095005, 6bba +0.000653564입니다. 작은 이득이지만 모든 해당 범위에서 양수이고 새 공개 표시 점수도0.954에 도달해 기존의 공개 결과 미확인 사유가 해소됐습니다. 이 근거로 한 자리는 C069, 다른 자리는 다른 좌표 head 구성과 기존 Transformer를 사용하는 C024를 권합니다. C067과 C069는 동일 Transformer를 쓰므로 두 자리를 모두 배정하지 않습니다.

C053+C024도 타당한 보수적 대안입니다. 위 추천은 두 배아의 중첩 crop과 학습 영역을 포함한 제한적 근거에서의 선택이며 비공개 우위나0.002 역전을 입증하지 않습니다. 현재 Auto Select의 실제 체크 상태 및 동점 처리 규칙은 확인하지 않았습니다.
