## 왜 +0.002~0.003이 어려웠는가

1. **작은 차이를 재는 기준부터 완전히 일치하지 않았다.** 복제 평가와 실제
   주최측 평가는 분열의 국소 연결 구조 판정 등이 다르다. 해시/실행 재현성만
   통과해도 평가 정의까지 같아지는 것은 아니다. 이 부분은 작업 방식의 문제다.
2. **배아 간 차이와 반복 선택의 한계가 크다.** 국소·97개 검증을 반복 보고
   후보를 골랐으므로 이미 적응적으로 사용한 개발 자료다. 새 모델에 대해 배아를
   완전히 나눴더라도 공개 detector/head는 두 배아를 이미 봤다. 전체 파이프라인의
   독립 일반화 성능을 증명하는 세 번째 로컬 집단은 없다.
3. **중간 지표 개선이 최종 추적 개선은 아니다.** 좌표 잔차나 부모 순위가
   좋아져도 정수 출력, 노드 대응, 후보 간선, Transformer, ILP, 후처리를 거쳐
   실제 정답 연결이 늘어야 점수가 오른다. 좌표만 좋아지고 매칭/그래프가 같으면
   연결 점수는 그대로일 수 있다. 검출 추가도 연결 이득과 전체 노드 수 항을
   함께 계산해야 한다. 75.6% 관측은 인과관계나 복구 가능 비율을 입증하지 않는다.
4. **전이 검증 모델을 실제 배포 모델로 바꾸는 과정도 별도 문제다.** C052의
   +0.001808은 배아별 반대 학습 모델 결과다. 배포용 가중치 평균 C053은
   +0.001109에 그쳤다. 이것만으로 평균이 손실의 유일 원인이라고 할 수는 없지만,
   배아 분리 모델의 이득을 고정 배포 모델의 이득으로 그대로 인용할 수 없다.
5. **일부 탈락 조건이 지나치게 보수적이었다.** 모든 잔차 집단/축이 좋아지고
   좋은 점의 평균 손해가 1e-12 이하라는 조건은 공식 점수 개선의 필요조건이
   아니다. 공식 점수의 유의미한 손익을 보기 전에 이런 대리지표만으로 모든
   방향을 닫는 것은 부적절하다. 다만 C063은 18/22 영상과 학습 배아 자체의
   전체 평균도 악화했고 C061/C064도 큰 손해를 보였다. 이를 단순 표본 부족이나
   엄격한 기준만의 탓으로 돌리거나 기존 실패 레시피를 튜닝해 재포장하지 않는다.

0.954는 95.4% 정확도가 아니다. 실제 목적함수는 노드 수로 조정한 연결 Jaccard와
0.1×분열 Jaccard의 합이다. ‘이미 거의 만점이므로 불가능하다’는 결론은 맞지 않다.

## 앞으로 적용할 검증 방식

- 22개는 실행·형식·큰 손해를 빠르게 찾는 용도로 한정한다. 작은 혼합 효과나
  한 하위집단의 미세 악화만으로 후보를 최종 폐기하지 않는다.
- 새로 학습하는 구성 요소는 전체 배아를 분리하고, 가능한 source 배아 자료를
  충분히 활용한다. crop 중복/클래스별 유효 감독량을 기록한다. 평가 배아로
  학습 강도·epoch·임계값을 고르는 반복 탐색은 피한다.
- 최종 후보는 원래 제출 좌표·writer를 거친 **실제 공식 평가**로 97개 전체를
  비교한다. 전체/양배아/22/나머지75/영화별 결과, TP/FP/FN과 노드 수 영향을
  함께 보고한다. 후보 이득이 적은 수의 영상에 의존하는지도 검사한다.
- 잔차·꼬리·좋은 점 보호는 진단과 위험 설명에 사용한다. 새 설계에서는 총점의
  실질 손익이 주 판단 기준이다. 실패 실험을 사후 기준 변경으로 성공 선언하지 않는다.
- 가치 있는 최종 후보에 한해 나머지102개를 범위 확장 점검으로 사용할 수 있다.
  추가102개 역시 독립 test가 아니다. 시간 비용을 계산하고 가장 유망한 후보에
  한 번 적용한다. 배포 학습/평가와 전이 검증을 명확히 구분한다.
- T4/해시/정확버전은 최종 제출물이 검증된 구현과 같은지 증명하는 단계다.
  과학적 일반화 검증의 대체물로 쓰지 않는다.
